# Peter Thelander

I build practical AI workflows and interactive applications, informed by a
financial-services perspective. My projects explore how language models can work
with useful tools, durable context, and independent verification—and how to make
those systems understandable and usable.

Alongside AI experiments, I enjoy building games and simulations, from browser-based
space flight to a phone-sized Pong game. Earlier projects include C++ algorithms
and experiments with financial data and machine learning.

## How I approach experiments

I am interested in the boundary between a compelling demonstration and dependable
software: clear state ownership, reproducible checks, useful interfaces, and honest
accounts of what failed as well as what worked. Project READMEs distinguish current
capabilities, prototypes, and historical learning work.

For historical C++ source and algorithm notes, see [BoggleSolver](https://github.com/peterthelander/BoggleSolver).

For a finance-focused case study, see [SPA](https://github.com/peterthelander/spa_description),
a public overview of a private financial-data and machine-learning project.
